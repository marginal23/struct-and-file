## Описание
Файл `cars.txt` содержит сведения об автомобилях: марка, год выпуска, фамилия владельца и номер. Программа выводит сведения об автомобилях заданной марки и определяет их средний возраст. Среди всех автомобилей программа находит самую старую машину.

## Входные данные
- С клавиатуры: имя файла (`cars.txt` или полный путь), марка автомобиля (например, `Toyota`) и текущий год (например, `2026`).
- Из файла `cars.txt`: одна машина на строке в формате `марка год фамилия номер`.

## Выходные данные
- Список автомобилей заданной марки.
- Средний возраст автомобилей этой марки.
- Самая старая машина среди всех автомобилей из файла.

## Как запустить
1. Положить `cars.txt` в папку проекта рядом с `Lab10.cpp`.
2. Открыть проект в Visual Studio и запустить без отладки: Ctrl+F5.
3. На вопрос о файле ввести `cars.txt` (или полный путь к файлу).
